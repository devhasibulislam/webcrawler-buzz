WebCrawler is an open-source domain crawling tool that lets you discover 
every publicly accessible page of any website. Paste a URL, hit crawl, 
and get a full report with page titles, meta descriptions, HTTP status 
codes, response times, indexability, and more — all in a clean table.

Built with Express.js + TypeScript on the backend, BullMQ + Redis for 
persistent job queuing, and Neon PostgreSQL for storage. No depth limit. 
Runs entirely in the background — close the tab and come back later via 
your tracking link or email notification.
